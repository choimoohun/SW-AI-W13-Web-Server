## 5. 과제에는 있는데 REQUIREMENTS.md와 어긋나는 것

1. **FR-05 수용 기준**에 "CGI 자식 프로세스 좀비 없음(`waitpid`)"이 남아 있음. 같은 절에서 CGI(안 A)는 "구현하지 않음"으로 결정 → 기준이 선택하지 않은 안에 대한 것.
2. **FR-06 결정 문구**가 "안 A(고정 워커 풀, 스레드 풀 + Bounded Task Queue) + 안 B 결합". 실제는 작업 큐 없는 워커별 이벤트 루프(D5). 큐가 있는 곳은 프록시 스레드뿐.
3. 과제 품질 항목의 "라우팅/프록시 전달 로직 **단위** 테스트"가 REQUIREMENTS에 따로 적혀 있지 않음.
4. 과제는 "Proxy **또는** Reverse Proxy — 둘 중 최소 한 가지"를 필수로 하되, REQUIREMENTS는 Reverse Proxy만 필수(Must)이고 Forward Proxy는 Could. 문서에 축소 이유가 있음(`REQUIREMENTS.md:99-101`), 의도된 스코프 차이.
5. 제출물 항목(팀 GitHub Projects 주소, 레포 주소, `WEEK13` WIL)이 REQUIREMENTS에 없음 → §4의 “GitHub Projects” 행으로.
