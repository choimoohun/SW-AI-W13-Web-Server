# 프로젝트 진행 상태

- **현재 단계** … 1.7에서 WSL 회귀 테스트, 단일 경로 부하 재측정, 혼합 부하, 동일 좌석 경합, 백엔드 중단·복구를 확인했다. [단계별 완료 기준](spec.md#작업-단위와-완료-기준)
- **현재 구현** … HTTP/1.1 연결당 요청 한 건, 예약 백엔드 한 대, 프록시 워커 4개와 큐 8칸을 사용한다. [전체 흐름](server.md) · [설계 결정](spec.md)
- **확인한 결과** … 기존 회귀 테스트 3개를 다시 실행해 모두 통과했다. 동시 요청 16개의 혼합 부하에서는 두 실행 모두 일부 POST가 `BrokenPipeError`로 끝났다. 상태별 건수와 기존 Valgrind 결과는 [검증 결과](results.md)에 있다.
- **다음 작업** … 과부하 시 POST 전송 실패가 발생하는 연결의 타이밍을 확인한다. 브라우저 두 탭에서 같은 좌석을 예약했을 때의 충돌 화면은 백엔드 동시 예약 판정과 별도로 확인한다.
