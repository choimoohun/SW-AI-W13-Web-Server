# 프로젝트 진행 상태

- **현재 단계** … 1.5 예약 API, 리버스 프록시, 예매 화면을 연결했다. [단계별 완료 기준](spec.md#작업-단위와-완료-기준)을 참고한다.
- **마지막으로 검증한 내용** … [README](../README.md)의 Docker 빌드·검증 명령으로 CMake 빌드와 CTest 2개(`http_split_post`, `http_static`)가 통과했다. 같은 Docker 환경에서 `curl`로 조회·예약·재조회·중복 예약의 `200`·`201`·`200`·`409`와 좌석 상태 변경을 확인했다. 백엔드 중단 뒤 API는 `502`, 정적 `GET /`는 `200`을 반환했다. `public/index.html`의 스크립트는 `node --check`를 통과했다.
- **다음 작업** … [직접 확인 가이드](dynamic/check.md)에 따라 브라우저에서 예약과 충돌 표시를 확인하고 프록시 타임아웃 `504`를 검증한다. 1.6 워커 풀은 설계 검토 중이다.
