# 프로젝트 진행 상태

- **현재 단계** … 1.6 워커 풀·과부하 처리·기한·신호 종료의 기능 검증을 마쳤다. 1.7에서는 제출 환경에서 최종 결과를 재현한다. [단계별 완료 기준](spec.md#작업-단위와-완료-기준)
- **현재 구현** … HTTP/1.1 연결당 요청 한 건, 예약 백엔드 한 대, 프록시 워커 4개와 큐 8칸을 사용한다. [전체 흐름](server.md) · [설계 결정](spec.md)
- **확인한 결과** … 예약 상태 변경, `502`·`504`, 느린 연결과 정적 응답의 동시 처리, `408`·`503`, 종료를 확인했다. 부하 수치와 Valgrind 결과는 [검증 결과](results.md)에 있다.
- **다음 작업** … 제출 환경에서 [회귀 테스트와 직접 확인](testing.md)을 한 번 재현한다. 브라우저 두 탭에서 같은 좌석을 예약했을 때의 충돌 화면은 백엔드 동시 예약 판정과 별도로 보고한다.
