# 연결별 I/O 기한

[설계 목차](../design.md) · [종료 흐름](shutdown.md) · [직접 확인](check.md)

느린 소켓이 워커를 계속 점유하지 않도록 기한을 둔다. `CLOCK_MONOTONIC`으로 계산한 기한까지 남은 시간만 `poll()`로 기다린다. 바이트가 조금 도착해도 각 구간의 기한을 다시 시작하지 않는다.

| 구간 | 기한 시작 | 처리 |
| --- | --- | --- |
| 클라이언트 요청 읽기 | 워커가 FD를 꺼내 요청을 읽기 시작한 뒤 헤더·본문 전체 5초 | `408 Request Timeout` 응답 시도 |
| 프록시 중계 | 백엔드 연결 시도부터 요청 전송·응답 수신까지 전체 3초 | 기한 초과 `504`, 연결 실패·잘못된 응답 `502` |
| 클라이언트 응답 쓰기 | 응답 헤더를 쓰기 직전부터 헤더·본문 전체 5초 | 도중에 막혔다면 전송을 멈추고 연결 정리 |

`wait_fd()`와 `set_nonblocking()`은 [io.c](../../src/io.c)에 있다. [http.c](../../src/http.c)는 클라이언트 소켓, [proxy.c](../../src/proxy.c)는 백엔드 소켓에 기한을 적용한다. 큐에서 기다린 시간은 요청 읽기 기한에 포함하지 않는다. 기한이 지난 연결은 닫고, 워커는 다음 FD를 꺼낸다.
