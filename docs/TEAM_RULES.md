# 팀 규칙

확정된 것만 적습니다. 합의하지 않은 내용은 여기에 두지 않습니다.

## 공통 규칙

- 알리고 싶은 것과 의견은 Discussion에 올립니다.
- 할 일은 Issue로 함께 정합니다. 논의 중 생긴 할 일도 Issue로 옮깁니다.
- 코드와 문서 변경은 PR로 올립니다. “무엇을, 왜 바꿨는지, 어떤 명령으로 확인했는지”를 적습니다.
- 리뷰 댓글은 파일과 재현 입력을 지정하고, 답변에는 판단 근거와 수정 결과를 적습니다.
- 실행하지 않은 테스트는 PASS로 적지 않습니다. 실패와 수정 기록은 지우지 않습니다.

## AI 활용 원칙

- 설계·구현·검증에서 AI 도움을 받되, 도입한 결과는 실행으로 확인한 뒤 채택한다.
- AI가 쓴 코드와 문서는 원리를 직접 설명할 수 있을 때만 반영한다.
- 역추적 검증은 구현자가 아니라 검증 역할이 맡는다([AGENTS.md](../AGENTS.md)).

## 아직 정하지 않은 것

팀 저장소, 기준 브랜치, 리뷰 승인 인원, 머지 방식은 합의 후 여기에 적습니다.
