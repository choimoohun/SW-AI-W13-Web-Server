# 팀 규칙

지금 확정된 것만 적습니다. 합의하지 않은 내용은 여기 두지 않습니다.

- 알리고 싶은 것과 의견은 Discussion에 올립니다.
- 할 일은 Issue로 올립니다. 논의 중 생긴 할 일도 Issue로 옮깁니다.
- 코드와 문서 변경은 PR로 올립니다. 무엇을 왜 바꿨는지, 어떤 명령으로 확인했는지 적습니다.
- 리뷰 댓글은 파일과 재현 입력을 지정합니다. 답변에는 판단 근거와 수정 결과를 적습니다.

## 아직 정하지 않은 것

팀 저장소, 기준 브랜치, 리뷰 승인 인원, 머지 방식은 합의 후에 여기에 적습니다.
