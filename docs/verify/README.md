# 실행 증거

여기에는 실제로 확인한 것만 둡니다. 설계나 구조에 대한 의견은 [../reviews/README.md](../reviews/README.md)에 있습니다.

| 문서 | 내용 |
|---|---|
| [TRACEABILITY.md](TRACEABILITY.md) | 요구사항이 문제·설계·구현·테스트로 이어지는지 |

"완료"라고 쓰려면 [VERIFICATION_LOG.md](VERIFICATION_LOG.md)에 기록이 있어야 합니다.
