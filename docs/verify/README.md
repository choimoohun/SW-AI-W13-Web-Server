# 검증 기록

여기에는 실제로 확인한 것만 둡니다.
실행하지 않은 것, 범위 밖인 것도 그대로 적습니다.

| 파일 | 내용 |
|---|---|
| [TRACEABILITY.md](TRACEABILITY.md) | 요구사항이 문제·설계·구현·테스트로 이어지는지 |
| [TEST_MATRIX.md](TEST_MATRIX.md) | 무엇을 검증하는지, 지금 상태가 어떤지 |
| [VERIFICATION_LOG.md](VERIFICATION_LOG.md) | 실제로 실행한 명령과 출력 요약 |

설계나 구조에 대한 판단은 여기에 두지 않고 [../reviews/README.md](../reviews/README.md)에 둡니다.

## 상태 값

- PASS: 실제로 실행해 통과
- FAIL: 실행했지만 실패
- NOT RUN: 아직 실행하지 않음
- OUT OF SCOPE: 이번 범위 밖

"완료"라고 적으려면 VERIFICATION_LOG.md에 기록이 있어야 합니다.
