# 협업 과정 기록

대화 전문을 그대로 붙이지 않습니다. **질문이 무엇을 바꿨는지**를 남깁니다.
이렇게 해야 나중에 "왜 이 방식이지?"를 물었을 때 문서가 답할 수 있습니다.

## 원칙

1. 질문 자체보다 질문이 드러낸 판단을 적습니다.
2. "AI가 그렇게 했다"가 아니라 "이 근거로 이렇게 확정했다"고 적습니다.
3. 바뀐 내용은 결정 기록이나 STEP 문서에 연결합니다.
4. 다음으로 미룬 것도 적습니다. 안 한 것을 완료로 바꾸지 않습니다.
5. 과거 표현을 지우기보다, 당시 기록과 현재 상태를 구분합니다.

## 기록 형식

```text
질문/지적: 무엇을 물었나
드러난 문제: 그 질문으로 무엇이 확인됐나
바뀐 것: 코드/문서/결정 중 무엇이 바뀌었나
근거: DECISIONS, STEP, VERIFICATION_LOG 링크
다음: 미룬 것이나 후속 확인
```

## 다음 단계에서 같은 방식으로 적을 것

- 로그인을 붙일 때: 왜 레디스 세션인지, JWT를 미룬 이유
- TLS/HTTP2를 붙일 때: 어디서 종료하는지, 로컬에 왜 안 넣는지
- 포워드 프록시를 붙일 때: 어떤 요청을 누구 대신 보내는지

이 문서는 협업 "로그"가 아니라 **판단이 남은 자리**입니다. 대화는 사라져도
결정과 근거가 남으면 다음 사람이 같은 고민을 다시 하지 않아도 됩니다.
